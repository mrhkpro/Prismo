RAG Widget — Final Vercel-ready package

1) Do NOT copy .venv into this package. Create it locally with setup.bat.
2) Local run: setup.bat
3) Vercel Environment Variables must contain the values from your local .env, especially:
   APP_ENV=production
   DATABASE_URL=<Supabase Transaction Pooler URL>
   SECRET_KEY=<your current secret>
   DEFAULT_PROVIDER_BASE_URL=https://racode-llm.partschool.ir/v1
   DEFAULT_PROVIDER_API_KEY=<your current provider key>
   # When direct Vercel -> provider traffic times out, use the relay instead:
   # AI_PROXY_BASE_URL=https://YOUR-RELAY-DOMAIN/v1
   # AI_PROXY_API_KEY=<relay key>
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=<your current admin password>
   ADMIN_ORG_NAME=ADMIN
   AI_REQUEST_TIMEOUT_SECONDS=120
   AI_CONNECT_TIMEOUT_SECONDS=20
   AI_MAX_RETRIES=0
   AI_MAX_OUTPUT_TOKENS=900
4) Deploy preview first: vercel.cmd
5) Check /api/health. Then log in and use Settings -> Test Connection.
6) In Settings -> Test Connection, the site now runs provider diagnostics. It shows DNS, stage, HTTP status, model, exception type and elapsed time without showing the API key.
7) If chat itself fails, the same technical details are shown inside the chat message and the response request ID is displayed.
8) If the error is DNS/connect/timeout, do NOT keep increasing timeouts. Configure the hosted relay:
   AI_PROXY_BASE_URL=https://YOUR-RELAY-DOMAIN/v1
   AI_PROXY_API_KEY=<relay key>
   See docs/RELAY_QUICKSTART.md.
9) Only after Preview works: vercel.cmd --prod

Git:
