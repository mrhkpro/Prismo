# Changelog — Prismo

این فایل یک نمای سریع از تغییرات اخیر است. جزئیات هر نسخه در فایل نسخه‌دار آن قرار دارد. برای شناخت رفتار جاری، ابتدا راهنماهای موضوعی را بخوانید؛ یادداشت‌های نسخه ممکن است توضیح رفتار تاریخی باشند.

## نقاط عطف قبلی

- [v2.8.9](CHANGELOG_2.8.9.md): انتخاب پورت Session Pooler برای اجرای Local + Supabase.
- [v2.8.8](CHANGELOG_2.8.8.md): سازگاری Local/Supabase و اعلان هشدار امنیتی در داشبورد.
- [v2.8.7](CHANGELOG_2.8.7.md): ترمیم ستون‌های اتصال مستقل Embedding در PostgreSQL.
- [v2.8.5](CHANGELOG_2.8.5.md): ورود گوگل، کش پاسخ و callback امن‌تر.
- [v2.7.0](CHANGELOG.md): مرکز تنظیمات، زبان فارسی/انگلیسی، پوسته‌های متعدد و بهبود تجربه‌ی کاربری.
- [v2.5.0](CHANGELOG.md): پوسته‌ی داشبورد، استریم، استخراج فایل، حیوان پیکسلی و هشدارهای مدیریت.
