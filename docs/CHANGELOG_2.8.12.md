# Prismo v2.8.12

- Saved chat models now appear in a collapsible list in the chat model card.
- Saved custom embedding models are persisted per user and shown in a collapsible list in the embedding card.
- Built-in ready-model warnings now say they do not work through the hosted site and explain that the project must be installed and run locally, with Supabase or without it.
- API keys remain server-side and are not rendered in the lists.
